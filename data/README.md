# Data release

The relevant data are distributed in the Zenodo archive,
<https://doi.org/10.5281/zenodo.21891845>.

The study itself draws on the public `multimolecule/rnacentral` and
`multimolecule/bprna-90` datasets from Hugging Face. The archive additionally
provides the exact derived inputs used for the reported results:

- the 25,000-sequence similarity-filtered RNAcentral holdout (`rnacentral_holdout/`);
- its `cd-hit-est-2d` audit JSON, recording the filtering statistics reported in
  the supplementary material;
- the processed bpRNA subset used for the structure analysis (`bprna/`); and
- a `SHA256SUMS` checksum manifest at the archive root.
